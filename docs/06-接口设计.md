## 6. API 设计

统一前缀 `/api`，响应体为 `R<T>`（RuoYi 约定，见 [§4.5](./03-核心链路.md)），`data` 承载业务数据；异常统一 HTTP 200 + `code:500`。

**序列化契约（三个都是「不写就出错」的项，实现见 `carbon-common-web` 的 `JacksonConfig`）**：
- **雪花 id 一律输出字符串**。19 位 id 超过 JS `Number.MAX_SAFE_INTEGER`（2^53-1），`JSON.parse` 会被四舍五入成另一个 id，页面表现是「列表能看、点详情 404」。只对装箱 `Long` 生效，所以 `TableDataInfo.total` 仍是数字，前端分页不用改。
- **时间一律 `yyyy-MM-dd HH:mm:ss`**。`spring.jackson.date-format` 不作用于 `LocalDateTime`，不显式注册就退化成 ISO-8601（`2026-10-27T09:59:31.756`），前端只能自己截字符串。反序列化同步注册，否则请求体回传的时间解析不了。时区见 [§3 时区约定](./02-数据模型.md)。
- **列表不返回大字段**。`GET /api/flows` 显式排除 `draft_dsl`（整张图的 JSON，几十 KB 起步），只在 `GET /api/flows/{id}` 返回。

**分页与参数约定（照搬 RuoYi）**：
- 分页入参：`pageNum`（默认 1）、`pageSize`（默认 10）、`orderByColumn`、`isAsc` → 封装为 `PageQuery`
- 分页出参：`TableDataInfo<T>` = `{ total, rows, code, msg }`
- 列表查询参数封装为 `XxxBo`（含 `searchValue`、`params` 扩展槽）

### 6.1 配置域

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/connectors` | 分页；参数 `keyword, category, status` + `pageNum, pageSize` |
| POST | `/api/connectors` | 新建，返回 id |
| GET | `/api/connectors/{id}` | 详情（含 auth） |
| PUT | `/api/connectors/{id}` | 更新 |
| DELETE | `/api/connectors/{id}` | 逻辑删除（有启用接口时拒绝） |
| PUT | `/api/connectors/{id}/status` | `{status:0\|1}` 启停；启用前校验配置完整性 |
| POST | `/api/connectors/{id}/auth/test` | 主动取 Token / 校验鉴权，返回是否成功与耗时 |
| GET | `/api/connectors/{id}/operations` | 接口列表 |
| POST | `/api/operations` | 新建接口 |
| GET/PUT/DELETE | `/api/operations/{id}` | 详情/更新/删除 |
| POST | `/api/invoke/{connectorCode}/{operationCode}` | **试调**：`{envCode, pathParams, query, headers, body, preScriptOverride, postScriptOverride}` |
| GET | `/api/envs` | 环境列表（**待补**：新建/更新/删除/set-default，当前只有只读列表） |
| GET | `/api/envs/vars` | 变量摊平视图（前端「变量扫描」用） |
| GET/POST/PUT/DELETE | `/api/apps[/{id}]` | 应用管理 |
| PUT | `/api/apps/{id}/secret` | 重置密钥（旧 secret 立即失效，明文只返回这一次） |
| GET | `/api/logs` | 分页；`connectorId, operationId, source, traceId, onlyFailed, beginTime, endTime` |
| GET | `/api/logs/{traceId}` | 该 traceId 下的**调用明细**（多行，按时间）+ 每行的 `flowRunId`（可空）。**不含编排步骤**——步骤树由前端再调 `/api/flow-runs/{runId}` |
| GET | `/api/logs/writer/status` | 异步落库器水位：`{queueSize, written, failed, dropped}`（进程内计数，重启归零，别当持久指标用） |
| GET | `/api/stats/overview` | 看板数据（**待补**） |
| GET | `/v3/api-docs/gateway` | 网关 OpenAPI 3（**待补**） |

### 6.2 编排域（P2）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/flows` | 列表（不含 `draftDsl`）/新建 |
| GET/PUT/DELETE | `/api/flows/{id}` | 读草稿（含 `draftDsl`）/ 存草稿（`dsl` 整体覆盖）/ 删除 |
| POST | `/api/flows/validate` | 传 `dsl` 直接校验，返回 `{valid, errors:[{code,message,nodeIds}]}`；结构化校验失败时 `code` 为 `EDGE_BACKWARD` / `EDGE_CROSSING` / `NO_CONVERGENCE`，`message` 带画布指引。**不挂 flowId**——未保存的草稿也要能校验 |
| POST | `/api/flows/{id}/publish` | `{remark}` → 生成新版本 |
| GET | `/api/flows/{id}/versions` | 版本列表 |
| POST | `/api/flows/{id}/run` | 同步执行（当前实现），返回 `{runId, traceId, status, output, stepCount, startedAt, …}` |
| GET | `/api/flow-runs` | 运行历史分页；`flowId, status` |
| GET | `/api/flow-runs/{id}` | 运行详情 `{run, steps}`，`steps` 按 `execIndex` 升序 |
| — | `POST /api/flows/{id}/rollback`、`GET /api/flows/runs/{runId}/stream`（SSE） | **待补**（画布/实时要用的两个入口） |

### 6.3 调度域（P3）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET/POST | `/api/jobs` | 列表（`flowId` 可选过滤，带 `nextFireTimes`）/新建（创建即注册 Quartz） |
| GET/PUT/DELETE | `/api/jobs/{id}` | 详情 / 更新（重注册 trigger）/ 删除 |
| POST | `/api/jobs/{id}/enable`、`/disable` | 启停（禁用即从 `QRTZ_JOB_DETAILS` 摘除） |
| POST | `/api/jobs/{id}/trigger` | 立即执行一次；**未启用时返回 `PARAM_INVALID`**（文案「任务未启用，先启用再立即执行」）——只有 `trigger` 会拦，别误以为 enable 不起作用 |

### 6.4 网关（对外）

| 方法 | 路径 | 说明 |
|---|---|---|
| ANY | `/gw/{connectorCode}/{operationCode}` | 签名鉴权；body 透传；变量从 query + JSON body 顶层采集 |
| POST | `/gw/flows/{flowCode}` | 触发已发布编排，body 作为 flow `input`（**待补**） |
| GET | `/gw/health` | 无鉴权存活探针（**待补**；目前用 `/actuator/health`） |
